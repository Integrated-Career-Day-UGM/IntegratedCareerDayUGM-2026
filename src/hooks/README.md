# Hooks

- `map/` — hooks exclusive to the map page: `useBoothFromUrl`,
  `useKeyboardShortcut`, `useKpiData`, `useShareBooth`.
- Root — Fluid Functionalism vendor hooks installed by the registry
  (`use-fluid-hover`, `use-keyboard-nav-gate`, `use-merge-split`,
  `use-touch-primary`). Do not move these: registry updates rewrite them at
  these paths.
